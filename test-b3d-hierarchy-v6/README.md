# B3D Hierarchy V6 — TEST 2026-10-01

Отдельная тестовая версия. `current-generator/` не изменяется.

Изменения после V5:

- исправлено наследование сложной фурнитуры: если connected OBJ-компонент уже однозначно принадлежит одному B3D-владельцу минимум на 70%, его оставшиеся непривязанные cap/fillet-треугольники наследуют тот же selectable-блок; компоненты с несколькими владельцами не объединяются;
- это закрывает выпадение отдельных частей ручек из фасадного блока без привязки к названию «ручка»;
- в режиме **Сильное** все импортированные B3D-листы Type=10000 переводятся только в feature-edge представление — заполненных proxy-box/«кирпичей» больше быть не должно, даже если отдельный подэлемент содержит меньше 500 треугольников;
- режимы остаются: **Нет / Среднее / Сильное**, по умолчанию **Среднее**;
- Win32 UI стабилизирован: главный UI-поток закреплён через LockOSThread; worker больше не меняет controls и не показывает MessageBox напрямую, а возвращает результат через PostMessage; переключатели режима блокируются только на время сборки.

- `Комод гардероб`: Strong 197246 → 12520 поверхностных треугольников; существующая B3D-иерархия ящиков/корпуса сохранена;
