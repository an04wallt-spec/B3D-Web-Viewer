# B3D Hierarchy V5 — TEST 2026-09-30

Отдельная тестовая версия. `current-generator/` не изменяется.

Изменения после V4:
- оставлены только 3 режима: **Нет / Среднее / Сильное**;
- по умолчанию выбран **Среднее**;
- **Среднее** сохраняет тела и облегчает плотную импортированную геометрию;
- **Сильное** больше не создаёт прямоугольные proxy-тела: у тяжёлых импортированных объектов поверхности удаляются, остаются только очищенные feature edges — границы и резкие переломы; внутренние рёбра триангуляции плоских поверхностей не выводятся;
- контуры отверстий и окружностей должны оставаться видимыми;
- выбор режима переведён с COMBOBOX на три radio-button, а режим считывается до запуска фоновой сборки. Это устраняет потенциальную блокировку UI из-за SendMessage из рабочего потока;
- иерархия B3D, 5/5 деталей ящиков и исправление радиусной верхней детали корпуса из V4 сохранены.
