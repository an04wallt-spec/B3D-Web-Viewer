# B3D Offline Generator — текущая рабочая версия

Контрольная архитектура проекта. Другие исторические направления в репозитории не являются production-маршрутом.

## Вход

В одной папке рядом с `Генератор.exe` пользователь вручную подготавливает:

- ровно один `.b3d`;
- ровно один `.obj`;
- ровно один `.mtl`;
- подпапку текстур, созданную БАЗИСом; имя подпапки может быть любым.

Генератор ничего не изменяет и не удаляет. Он читает MTL, находит используемые текстуры в подпапках и создаёт один автономный HTML.

## Выход

`<имя B3D> — 3D.html`

HTML работает офлайн и содержит:

- индексированную геометрию из OBJ;
- материалы и текстуры;
- исходный B3D байт-в-байт;
- WebGL-просмотрщик.

## Подтверждённые функции viewer

- текстурированный вид;
- контуры деталей;
- контуры включены по умолчанию;
- кнопка `Не показывать контуры` / `Показать контуры`;
- режим `Без текстур`;
- `Прозрачность 30%` (30% прозрачности / 70% непрозрачности);
- настройка текстур по материалам: зеркальное повторение, масштаб X/Y, смещение X/Y, поворот, сброс;
- `schkaf@yandex.ru` в правом верхнем углу, клик копирует адрес;
- распознавание логических фасадных блоков по B3D для модели `Шкаф в прихожей`;
- кликом можно добавлять несколько деталей/фасадов в общее выделение;
- повторный клик убирает объект из выделения;
- `Скрыть выбранное` скрывает все выбранные объекты одним действием;
- `Показать всё` возвращает скрытые объекты;
- `Esc` полностью снимает текущее выделение.

## Сборка Windows

Требуется Go 1.22+.

```powershell
$env:GOOS="windows"
$env:GOARCH="amd64"
go build -ldflags="-s -w -H=windowsgui" -o "Генератор.exe" .
```

## Правило дальнейшей разработки

Не менять рабочий маршрут B3D + OBJ + MTL + textures → один offline HTML. Новые функции добавляются поверх этой версии с сохранением возможности отката к стабильной точке.
