# B3D Offline Generator — текущая рабочая линия

Это контрольная точка текущего рабочего проекта. Исторические направления в репозитории не считаются production-маршрутом.

## Рабочая схема

Пользователь вручную кладёт рядом с Генератор.exe:
- один B3D;
- один OBJ;
- один MTL;
- подпапку текстур, созданную БАЗИСом (имя подпапки может быть любым).

Генератор читает MTL, находит текстуры в подпапках и создаёт один автономный HTML. Исходные файлы не изменяются и не удаляются.

## Подтверждённые функции

- индексированная геометрия;
- текстуры и настройка материалов;
- зеркальное повторение текстур;
- контуры;
- режим без текстур;
- прозрачность 40%;
- schkaf@yandex.ru с копированием адреса кликом;
- распознавание фасадных блоков в B3D на модели «Шкаф в прихожей»;
- скрытие выбранных деталей/фасадных блоков;
- возврат скрытых объектов.

## Текущая кандидат-версия после фасадных блоков

Добавлено без изменения геометрии и существующего маршрута:
- мультивыбор: каждый следующий клик добавляет объект к выделению, повторный клик убирает его;
- «Скрыть выбранное» скрывает все выбранные объекты одним нажатием;
- Esc полностью снимает выделение;
- текстурированный вид с контурами включён по умолчанию;
- кнопка контуров по умолчанию называется «Не показывать контуры», после отключения — «Показать контуры».

## Правило разработки

Не менять рабочий маршрут B3D + OBJ + MTL + textures → один offline HTML. Новые функции добавляются поверх подтверждённой версии с сохранением точки отката.
