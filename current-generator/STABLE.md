# PRO Stable — 2026-09-15

Эта версия подтверждена пользователем как рабочая и является текущей основной контрольной точкой проекта.

Рабочий маршрут: B3D + OBJ + MTL + папка текстур БАЗИС → один автономный HTML без внешних зависимостей.

## Подтверждено в PRO

- индексированная геометрия;
- Facade Mapping V2 по реальной структуре B3D;
- мультивыбор и повторный клик для снятия отдельного выбора;
- Esc для полного снятия выделения;
- «Скрыть выбранное» и «Показать всё»;
- контуры включены по умолчанию;
- режим «Без текстур» сделан светлым;
- общая прозрачность 30%;
- настройка UV, зеркальное повторение, масштаб, смещение и угол текстуры;
- локальная замена текстуры и возврат исходной;
- отдельная прозрачность для материалов, в названии которых есть «стекло» или «glass»;
- адаптивный интерфейс для компьютера и смартфона;
- уменьшенные мобильные кнопки;
- ползунок разреза расположен в верхней строке рядом с почтой;
- синий индикатор заполнения ползунка разреза на компьютере и смартфоне;
- фронтальный вид с габаритами ширины и высоты изделия;
- вид сверху с габаритами ширины и глубины;
- вид слева с габаритами высоты и глубины;
- служебные сборки «стена/стены/пол/потолок» не участвуют в габаритных размерах изделия;
- вертикальный, горизонтальный и фронтально-глубинный разрезы;
- локальное заполнение сечений без заливки пустот;
- контуры пересечённых деталей на разрезе;
- слегка тонированная плоскость разреза;
- генератор собирается как GUI-приложение без отдельного консольного окна.

## Камера

- «Вписать» сохраняет текущий пользовательский ракурс и только вписывает всю модель в окно;
- «Исходный вид» возвращает фиксированный перспективный ракурс слева направо с камерой по вертикальному центру модели, без взгляда сверху вниз, и полностью вписывает модель.
