# Stable Working — 2026-09-07

Эта версия подтверждена пользователем как рабочая и является текущей контрольной точкой.

Рабочий маршрут: B3D + OBJ + MTL + папка текстур БАЗИС → один автономный HTML.

Подтверждено: индексированная геометрия; Facade Mapping V2 по реальной структуре B3D; мультивыбор; Esc для полного снятия выделения; скрытие выбранного и «Показать всё»; контуры включены по умолчанию; прозрачность 30%; светлый режим «Без текстур»; настройка и локальная замена текстур; уменьшенная мобильная панель управления.

Камера зафиксирована так:
- «Вписать» сохраняет текущий пользовательский ракурс и только вписывает всю модель в окно;
- «Исходный вид» возвращает фиксированный перспективный ракурс слева направо с камерой по вертикальному центру модели, без взгляда сверху вниз, и полностью вписывает модель в окно.
