# B3D Hierarchy — TEST 2026-09-30

Это вторая тестовая версия механизма блоков/сборок. `current-generator/` не изменяется.

Главное изменение относительно первого Generic Groups TEST:

- структура B3D является источником истины;
- любой не-boolean узел `Obj`, содержащий дочерние `Obj`, считается структурным блоком/сборкой независимо от имени и Type;
- OBJ сначала разбивается на целые физические connected components;
- каждая целая OBJ-деталь сопоставляется с конкретным geometry-bearing leaf-объектом B3D;
- после сопоставления деталь наследует реального родителя из дерева B3D;
- больше нет присвоения группы по центру каждого треугольника;
- фасадная логика остаётся sticky/fallback, чтобы не сломать Facade Mapping V2.

Целевой контроль: у ящика 5/5 деталей должны принадлежать одному блоку ящика, а все детали `Блок1` — своему корпусному блоку.
