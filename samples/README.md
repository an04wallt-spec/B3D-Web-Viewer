# Reference samples

Эта папка предназначена для эталонных `.b3d`, на которых проверяется обратная совместимость парсера и геометрического движка.

Текущий основной эталон:

```text
Стол_3100х750х1300.b3d
```

Файл должен быть положен сюда под этим именем для запуска регрессионного теста.

Viewer8.exe в репозиторий не добавляем: он используется только как внешний исследовательский эталон и не является частью проекта.
