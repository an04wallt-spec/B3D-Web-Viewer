# B3D Offline Generator

Текущая production-версия проекта — **PRO Stable 2026-09-15**.

## Рабочая схема

В одной папке рядом с `Генератор.exe` пользователь вручную размещает:
- один `.b3d`;
- один `.obj`;
- один `.mtl`;
- подпапку текстур, созданную БАЗИСом.

Генератор создаёт один автономный `<имя B3D> — 3D.html` без внешних зависимостей и без интернета.

## PRO Stable 2026-09-15

Подтверждено:
- индексированная геометрия;
- Facade Mapping V2;
- текстуры, UV-настройки, зеркальное повторение и локальная замена текстур;
- отдельная прозрачность материалов «стекло» / `glass`;
- мультивыбор, скрытие и восстановление объектов;
- контуры, светлый режим без текстур и общая прозрачность 30%;
- «Вписать» сохраняет текущий ракурс;
- «Исходный вид» возвращает центрированный перспективный стартовый ракурс;
- фронтальный, верхний и левый ортогональные виды с основными габаритами изделия;
- исключение служебных сборок «стена/стены/пол/потолок» из габаритных размеров;
- вертикальный, горизонтальный и фронтально-глубинный разрезы;
- локальное заполнение и контуры сечений;
- лёгкая тонировка плоскости разреза;
- адаптивный мобильный интерфейс и верхний ползунок разреза;
- синий индикатор заполнения ползунка;
- GUI-сборка генератора без отдельного консольного окна;
- один и тот же автономный HTML используется как универсальный выходной файл.

## Содержимое репозитория

В `current-generator/` хранится только актуальная стабильная точка:
- `SOURCE.zip` — исходники;
- `SHA256.txt` — контрольные суммы;
- `STABLE.md` — описание текущей PRO Stable версии.

Дальнейшие изменения выполняются поверх этой точки с возможностью отката.
