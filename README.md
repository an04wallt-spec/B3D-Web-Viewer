# B3D Web Viewer

Новый веб-вьювер файлов БАЗИС `.b3d`, создаваемый с нуля на основе прямого разбора формата B3D.

## Цель

Не воспроизводить старый Viewer8 визуальными догадками, а построить корректную цепочку:

`B3D → Model tree → панели/контуры/операции → итоговая 3D-геометрия → WebGL/Three.js`

## Текущий статус

### Парсер B3D

На эталонном файле `Стол_3100х750х1300.b3d` подтверждено:

- сигнатура `BZ85`;
- автоматический поиск основного zlib-потока модели;
- словарь полей сериализации;
- извлечение текущей ветки `Model` без `Undo`/истории редактирования;
- дерево `Obj`;
- ID, типы, имена, материалы, толщины и трансформации;
- `Contour` и `Trajectory`;
- сегмент `0x10` — линия;
- сегмент `0x12` — круговая дуга: центр, начало, конец и направление;
- `Cuts` и параметры операций, включая четверть, спил 45° и радиусные обработки.

На текущем эталоне найдено 62 объекта, из них 37 панелей типа `4002`.

### Геометрический движок — stage 1

`geometry/geometry.py` уже строит реальные треугольные mesh-поверхности панелей типа `4002`:

- собирает контур даже при произвольном порядке сегментов;
- правильно разворачивает встречные сегменты;
- строит настоящие круговые дуги по центру/началу/концу;
- триангулирует внешний контур;
- выдавливает его на толщину панели;
- применяет вложенные quaternion-трансформации B3D;
- переводит локальную геометрию детали в мировые координаты;
- сохраняет `Cuts` как структурированные метаданные для следующего этапа.

Ключевая регрессионная проверка на исходном столе:

- построено **37 из 37 панелей**;
- ошибок геометрии: **0**;
- итоговый bounding box: **3100 × 750 × 1300 мм** — точно соответствует габариту исходной модели.

Операции `Cuts` пока намеренно не вычитаются из solid. Это следующий этап: сначала типы операций должны быть воспроизведены корректно, без визуальных догадок.

## Структура

```text
parser/
  b3d_parser.py       # reverse-engineered B3D parser

geometry/
  geometry.py         # B3D model tree → triangle meshes панелей

tests/
  test_b3d_parser.py  # регрессия формата
  test_geometry.py    # регрессия геометрии и габаритов

docs/
  B3D_FORMAT_NOTES.md # подтверждённые сведения о формате

samples/
  Стол_3100х750х1300.b3d

.github/workflows/
  tests.yml           # автоматические регрессионные тесты

viewer/               # будущий браузерный 3D-вьювер
```

## Запуск парсера

```bash
python parser/b3d_parser.py samples/Стол_3100х750х1300.b3d --summary
```

Экспорт дерева модели в JSON:

```bash
python parser/b3d_parser.py samples/Стол_3100х750х1300.b3d -o model.json
```

## Построение mesh-геометрии

```bash
python geometry/geometry.py samples/Стол_3100х750х1300.b3d -o geometry.json
```

## Проверка

```bash
python -m unittest discover -s tests -v
```

Эти же тесты автоматически запускаются GitHub Actions при каждом push/PR.

## Принцип разработки

Сначала доказываем корректность геометрии на эталонных B3D. Интерфейс и WebGL подключаются только после того, как слой `B3D → geometry` воспроизводимо даёт правильную модель.
