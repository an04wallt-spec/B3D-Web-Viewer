# B3D Web Viewer

Новый веб-вьювер файлов БАЗИС `.b3d`, создаваемый с нуля на основе прямого разбора формата B3D.

## Цель

Не воспроизводить старый Viewer8 визуальными догадками, а построить корректную цепочку:

`B3D → Model tree → панели/контуры/операции → итоговая 3D-геометрия → WebGL/Three.js`

## Текущий статус

Первый этап уже работает на эталонном файле `Стол 3100х750х1300.b3d`:

- распознаётся сигнатура `BZ85`;
- автоматически находится основной zlib-поток модели;
- читается словарь полей сериализации;
- извлекается текущая ветка `Model` без входа в `Undo`/историю редактирования;
- восстанавливается дерево `Obj`;
- читаются ID, типы, имена, материалы, толщины и трансформации;
- декодируются `Contour` и `Trajectory`;
- подтверждены сегменты `0x10` (линия) и `0x12` (дуга);
- читаются `Cuts` и параметры операций, включая четверть, спил 45° и радиусные обработки.

На текущем эталоне найдено 62 объекта, из них 37 панелей типа `4002`.

## Структура

```text
parser/
  b3d_parser.py       # текущий reverse-engineered B3D parser

tests/
  test_b3d_parser.py  # регрессионная проверка на эталонном B3D

docs/
  B3D_FORMAT_NOTES.md # подтверждённые сведения о формате

samples/              # локальные эталонные B3D (не публикуются автоматически)
viewer/               # будущий браузерный 3D-вьювер
```

## Запуск парсера

```bash
python parser/b3d_parser.py samples/Стол_3100х750х1300.b3d --summary
```

Экспорт дерева модели в JSON:

```bash
python parser/b3d_parser.py samples/Стол_3100х750х1300.b3d -o model.json
```

## Проверка

Положить эталонный файл в:

```text
samples/Стол_3100х750х1300.b3d
```

и запустить:

```bash
python -m unittest tests.test_b3d_parser
```

Если файла нет, тест корректно пропускается.

## Принцип разработки

Сначала доказываем корректность геометрии на эталонных B3D. Интерфейс и WebGL подключаются только после того, как слой `B3D → geometry` воспроизводимо даёт правильную модель.
