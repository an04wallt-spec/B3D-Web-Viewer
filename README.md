# B3D Offline Generator

Рабочий генератор автономных HTML-моделей для БАЗИС-Мебельщик 24.

## Текущий рабочий маршрут

В одну папку рядом с `Генератор.exe` кладутся:

- один `.b3d`;
- один `.obj`;
- один `.mtl`;
- подпапка текстур, созданная БАЗИСом; имя папки может быть любым.

Генератор создаёт один автономный HTML и не изменяет исходные файлы.

## Стабильная версия

Контрольная версия: **2026-09-06**.

Подтверждено в работе:

- индексированная геометрия;
- текстуры и ручная настройка материалов;
- зеркальное повторение текстур;
- контуры включены по умолчанию;
- режим без текстур;
- прозрачность 30%;
- распознавание блоков `фасад` из B3D;
- мультивыбор;
- скрытие выбранных объектов и возврат скрытых;
- `Esc` снимает всё выделение;
- `schkaf@yandex.ru` копируется кликом.

## Что хранится в репозитории

Только актуальная стабильная линия генератора. Старые экспериментальные направления, Viewer3D/VRML, собственный B3D-реконструктор, старые probes, тесты и workflows удалены как неиспользуемые.

В `current-generator/` лежат контрольная запись стабильной версии, SHA-256 и архив актуальных исходников.

Дальнейшие изменения выполняются только поверх стабильной версии с возможностью отката.
