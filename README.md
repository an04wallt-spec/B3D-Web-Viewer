# B3D Offline Generator

Текущая production-версия проекта.

## Рабочая схема

В одной папке рядом с `Генератор.exe` пользователь вручную размещает:
- один `.b3d`;
- один `.obj`;
- один `.mtl`;
- подпапку текстур, созданную БАЗИСом.

Генератор создаёт один автономный `<имя B3D> — 3D.html` без внешних зависимостей и без интернета.

## Stable Final 2026-09-07

Подтверждено:
- индексированная геометрия;
- текстуры и настройка UV;
- зеркальное повторение;
- локальная замена текстуры и возврат исходной;
- контуры включены по умолчанию;
- режим без текстур;
- прозрачность 30%;
- Facade Mapping V2: чтение настоящей структуры B3D и сопоставление фасадных блоков с OBJ;
- мультивыбор;
- скрытие выбранных объектов;
- `Показать всё`;
- `Esc` снимает выделение;
- один и тот же автономный HTML используется как универсальный выходной файл.

Экспериментальная отдельная Apple-compat ветка в production не используется.

## Содержимое репозитория

В `current-generator/` хранится только актуальная стабильная точка: исходники, контрольная сумма и описание версии.
